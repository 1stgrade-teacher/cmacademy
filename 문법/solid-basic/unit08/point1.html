11. 가정법 과거 (Subjunctive Past)

★현재 사실과 반대되거나 실현 가능성이 희박한 일을 가정할 때 사용합니다.
🗂 가정법 과거의 구조
If절 (조건)주절 (결과)의미/시점
If + 주어 + 과거동사 (be는 were)주어 + 조동사과거(would/could 등) + 동사원형현재 사실의 반대 (~라면 …할 텐데)
If I were at home, I would feel more comfortable.
만약 내가 집에 있다면, 더 편안하게 느낄 텐데. — 현재 집에 없어서 불편하다는 의미
If the weather were warmer, we would eat dinner outside.
날씨가 더 따뜻하다면, 우리는 밖에서 저녁을 먹을 텐데. — 현재 날씨가 춥다는 사실의 반대

22. 가정법 과거완료 (Subjunctive Past Perfect)

★과거 사실과 반대되는 일이나 실현되지 못한 과거의 일을 가정할 때 사용합니다.
🗂 가정법 과거완료의 구조
If절 (조건)주절 (결과)의미/시점
If + 주어 + had p.p.주어 + 조동사과거 + have p.p.과거 사실의 반대 (~했더라면 …했을 텐데)
If you had come to the party, you would have enjoyed it.
만약 네가 파티에 왔었더라면, 너는 그것을 즐겼을 텐데. — 과거에 파티에 오지 않아 즐기지 못했다는 의미
If I had known the truth, I would have told you.
내가 진실을 알았더라면, 너에게 말해 주었을 텐데. — 과거에 진실을 몰랐다는 사실의 반대

33. 혼합 가정법 (Mixed Subjunctive)

★과거의 사실이 현재까지 영향을 미칠 때 사용하며, 보통 'now'와 같은 현재 표시어구가 동반됩니다.
🗂 혼합 가정법의 구조
If절 (과거 사실 가정)주절 (현재의 결과 가정)핵심 특징
If + 주어 + had p.p.주어 + 조동사과거 + 동사원형과거에 ~했더라면 (지금) …할 텐데
If he had studied harder, he would be able to answer the question now.
그가 공부를 더 열심히 했었더라면, 그는 지금 그 질문에 답할 수 있을 텐데. — 과거의 불성실함이 현재의 실력에 영향을 미침
If I had taken the map, I would not be lost now.
내가 지도를 챙겼더라면, 지금 길을 잃지 않았을 텐데. — 과거의 행동이 현재의 상태를 결정함

44. 단순 조건문 vs. 가정법

★단순 조건문은 실현 가능성이 있는 일을, 가정법은 사실과 반대되거나 실현 불가능한 일을 나타냅니다.
🗂 조건문과 가정법 비교
구분If절 시제내용
조건절현재 시제 (미래 대용)실제 일어날 가능성이 있음
가정법과거 시제현재 사실과 반대됨
If the weather is unfavorable, the class will be canceled.
날씨가 좋지 않으면 수업은 취소될 것이다. — 실제로 날씨가 나빠질 가능성이 있는 조건
If I had enough money, I would buy that car.
내가 충분한 돈이 있다면, 그 차를 살 텐데. — 현재 돈이 없다는 사실을 가정함
