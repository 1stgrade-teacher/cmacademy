11. 과거의 습관과 상태: used to vs. would

★used to는 과거의 규칙적인 습관이나 상태를 나타내며, 현재는 더 이상 그렇지 않음을 의미합니다.
🗂 used to와 would의 차이
구분used to + 동사원형would + 동사원형
과거의 습관O (~하곤 했다)O (~하곤 했다)
과거의 상태O (~이었다/있었다)X (사용 불가)
현재와의 관계현재는 아님을 강하게 시사단순한 과거의 행동에 초점
We used to think the brain never changed, but we now know this is not true.
우리는 뇌가 결코 변하지 않는다고 생각하곤 했으나, 이제는 이것이 사실이 아님을 안다. — 과거의 지속적인 생각(상태)을 나타냄
There used to be a theater here. Now there’s a library.
여기에 극장이 있었으나, 지금은 도서관이 있다. — 과거의 존재(상태)를 나타내며 would로 대체 불가

22. 혼동하기 쉬운 used to 관련 표현

★to 뒤에 동사원형이 오는지, (동)명사가 오는지에 따라 의미가 완전히 달라집니다.
🗂 be used to의 두 가지 쓰임
형태의미성격
be used to + 동사원형~하기 위해 사용되다use의 수동태 (to부정사)
be used to + (동)명사~에 익숙하다익숙함을 나타내는 형용사구 (전치사 to)
The word “introvert” is used to describe someone who likes being by themselves.
“내향적인 사람”이라는 단어는 혼자 있는 것을 좋아하는 누군가를 묘사하기 위해 사용된다. — 주어가 사물이며 수동의 의미로 쓰임
My family is used to spending a lot of time outdoors.
우리 가족은 야외에서 많은 시간을 보내는 데 익숙하다. — to가 전치사이므로 뒤에 동명사 spending이 옴

33. [요약] used to 핵심 포인트

★문장의 주어가 사물인지 사람인지, 문맥상 '상태'인지 '동작'인지를 파악하는 것이 핵심입니다.
🗂 used to 구문 총정리
구조해석핵심 문법
used to + V~하곤 했다, ~이었다조동사 (상태/습관)
be used to + V~하는 데 사용되다수동태 (to부정사의 부사적 용법)
be used to + V-ing~하는 데 익숙하다전치사 to (명사/동명사 목적어)
I used to be shy, but I am used to speaking in public now.
나는 예전에 수줍음을 탔었지만, 지금은 대중 앞에서 말하는 것에 익숙하다. — 과거의 상태(used to)와 현재의 익숙함(be used to V-ing) 비교
