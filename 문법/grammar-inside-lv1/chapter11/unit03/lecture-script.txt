1.mp3   (슬라이드 1)
안녕하세요, 여러분! 오늘은 because와 if, 그리고 that이라는 세 친구를 만나 볼 거예요. 이 세 단어는 중학교 시험에 정말 자주 나오는 접속사라서 오늘 확실히 정리해 두면 큰 도움이 될 거예요. 이유를 말할 때, 조건을 말할 때, 그리고 문장 안에서 덩어리를 만들 때 각각 어떻게 쓰이는지 예문으로 하나씩 확인해 볼게요. 어렵지 않으니까 편하게 따라와 주세요.

────────────────────────
2.mp3   (슬라이드 2)
먼저 because예요. because는 앞에 나온 일의 이유를 뒤에서 설명해 주는 접속사예요. 예를 들어 내가 이 집을 좋아하는 이유가 멋진 정원 때문이라면 because로 그 이유를 붙여 주면 되죠. 그리고 if는 만약 그런 조건이 되면 이렇게 된다는 뜻을 나타내요. 여기서 꼭 기억할 점은 if절 안에서는 미래의 일이라도 will을 쓰지 않고 현재시제를 쓴다는 거예요.

────────────────────────
3.mp3   (슬라이드 2)
첫 번째 예문이에요. I like this house because it has a nice garden. 나는 이 집이 멋진 정원을 가지고 있어서 좋다라는 뜻이에요. 내가 이 집을 좋아하는 이유가 바로 멋진 정원이 있다는 것이죠. 이렇게 because 뒤에 이유를 설명하는 주어와 동사가 통째로 왔다는 점을 꼭 봐 주세요.

────────────────────────
4.mp3   (슬라이드 2)
다음 예문이에요. We'll be happy if we win the game tonight. 오늘 밤 경기에서 우리가 이긴다면 행복할 것이다라는 뜻이에요. 오늘 밤 경기는 미래의 일이지만 if절 안에서는 will을 쓰지 않고 win이라는 현재시제를 썼어요. will은 뒤쪽에만 온다는 것도 함께 기억해 주세요.

────────────────────────
5.mp3   (슬라이드 2)
이번에는 제가 하나 더 준비했어요. I was late because of the heavy rain. 나는 심한 비 때문에 늦었다라는 뜻이에요. 여기서는 because가 아니라 because of가 쓰였고 뒤에 the heavy rain이라는 명사 덩어리가 왔어요. 뒤에 주어와 동사가 없으면 because of라고 생각하면 쉬워요.

────────────────────────
6.mp3   (슬라이드 2)
그리고 because of라는 표현도 조심해야 해요. because 뒤에는 주어와 동사가 있는 절이 오지만 because of 뒤에는 명사나 명사 덩어리가 와요. 그래서 because of the rain처럼 명사가 오고 because it rains처럼 절이 오면 because를 써야 해요.

────────────────────────
7.mp3   (슬라이드 3)
이제 that이에요. that은 주어와 동사를 데리고 다니면서 문장 안에서 명사처럼 주어, 목적어, 보어 역할을 할 수 있어요. 주어 자리에 that절이 오면 문장이 너무 길어지니까 보통 가주어 it을 앞에 세우고 진짜 주어인 that절은 뒤로 보내요. 반대로 think나 know 같은 동사의 목적어로 쓰인 that은 말할 때 자주 생략되고, 보어로 쓰인 that은 보통 생략하지 않아요.

────────────────────────
8.mp3   (슬라이드 3)
첫 번째 예문이에요. It is true that Andy likes Lisa. Andy가 Lisa를 좋아하는 것은 사실이다라는 뜻이에요. 앞에 있는 it은 특별한 뜻이 없는 가주어이고 진짜 주어는 뒤에 있는 that Andy likes Lisa예요. 이렇게 긴 주어를 뒤로 보내는 것이 영어의 자연스러운 순서라는 점을 기억해 주세요.

────────────────────────
9.mp3   (슬라이드 3)
다음 예문이에요. I think that Andrew is funny. 나는 Andrew가 웃기다고 생각한다라는 뜻이에요. 여기서 think 뒤에 온 that은 목적어절을 이끌면서 생략할 수도 있어요. 그래서 I think Andrew is funny라고 해도 같은 뜻이 된답니다.

────────────────────────
10.mp3   (슬라이드 3)
마지막 예문이에요. The problem is that I don't know the answer. 문제는 내가 답을 알지 못한다는 것이라는 뜻이에요. is 뒤에서 주어의 내용을 설명해 주는 보어 자리에 that절이 왔어요. 보어 자리에서는 that을 생략하지 않는다는 점도 함께 기억해 주세요.

────────────────────────
11.mp3   (슬라이드 3)
한 가지 더 알려 줄게요. 목적어로 쓰인 that은 편하게 생략할 수 있지만 주어나 보어 자리에 쓰인 that은 보통 생략하지 않아요. 시험에서는 이 차이를 묻는 문제가 자주 나오니까 꼭 기억해 두세요.

────────────────────────
12.mp3   (슬라이드 4)
첫 번째 실수예요. If we will hurry, we will catch the bus라고 쓰면 틀려요. 조건을 나타내는 if절에서는 미래의 일이라도 will을 쓰지 않고 현재시제 hurry를 써야 하죠. 그래서 If we hurry, we will catch the bus가 맞아요.

────────────────────────
13.mp3   (슬라이드 4)
두 번째 실수예요. The problem is if I don't have enough money라고 하면 어색한 문장이 돼요. 문제의 내용을 설명하는 보어 자리에는 if가 아니라 접속사 that을 써야 하거든요. 그래서 The problem is that I don't have enough money가 맞아요.

14.mp3   (슬라이드 4)
세 번째 실수예요. I think it Julia should be class president라고 하면 뜻이 통하지 않아요. think 뒤에서 목적어절을 이끄는 자리에는 it이 아니라 that을 쓰거나 아예 생략해야 하죠. 그래서 I think that Julia should be class president 또는 I think Julia should be class president가 맞아요.
