CHAPTER 08 · 대명사 · Point 3

some, any: 정확하지 않은 수량

P1 P2 P3 P4 P5 P6 P7 P8 P9
Point 3 some, any: 정확하지 않은 수량
some과 any는 '몇몇의, 약간의'라는 뜻으로 정확하지 않은 수량을 나타냅니다.
  • some: 주로 긍정문, 권유의 의문문에서 사용
  • any: 주로 부정문, 일반적인 의문문, 조건문에서 사용
EXAMPLE
I have some money.
나는 약간의 돈이 있다. (긍정문)
Do you have any questions?
질문 있으세요? (의문문)
Would you like some coffee?
커피 좀 드시겠어요? (권유)
