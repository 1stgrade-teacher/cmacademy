Point 10 used to: 과거의 습관이나 상태
used to + 동사원형은 '(예전에는) ~하곤 했다 / ~였다'라는 뜻으로, 지금은 더 이상 그렇지 않은 과거의 습관이나 상태를 나타냅니다.
EXAMPLE
I used to play the piano when I was young.
나는 어렸을 때 피아노를 치곤 했다. (지금은 안 침)
There used to be an old tree here.
여기 예전에 오래된 나무가 하나 있었다. (지금은 없음)
He used to be shy, but now he's confident.
그는 예전에 수줍었지만, 지금은 자신감이 있다.
TIP used to(과거의 습관/상태) vs. be used to -ing(~하는 데 익숙하다)를 헷갈리지 않도록 주의하세요.
