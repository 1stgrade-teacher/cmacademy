🎧 Unit 5. 일반동사의 부정문 완벽 정리 — AI강의

11. don't를 사용하는 부정문

주어가 1인칭, 2인칭이거나 복수형일 때 'do not'의 줄임말인 don't를 사용합니다. ★주어가 I, You, We, They일 때 사용함에 유의하세요.
🗂 주어에 따른 don't 사용법
주어의 종류부정문 형태예시
1인칭 단수 (I)don't + 동사원형I don't like
2인칭 단수/복수 (You)don't + 동사원형You don't go
1인칭/3인칭 복수 (We, They)don't + 동사원형They don't have
I like strawberries. I don't like peaches.
나는 딸기를 좋아한다. 나는 복숭아를 좋아하지 않는다. — 주어가 I이므로 don't를 사용
The kids go to the park. They don't go to school.
아이들은 공원에 간다. 그들은 학교에 가지 않는다. — The kids는 복수(They)이므로 don't를 사용

22. doesn't를 사용하는 부정문

주어가 3인칭 단수(He, She, It)일 때는 'does not'의 줄임말인 doesn't를 사용합니다. ★이때 동사의 -s/es는 사라지고 반드시 동사원형이 옵니다.
🗂 3인칭 단수 주어와 doesn't
주어 (3인칭 단수)부정문 형태핵심 규칙
He (남자 한 명)doesn't + 동사원형doesn't get up (O)
She (여자 한 명)doesn't + 동사원형doesn't has (X) -> have (O)
It (사물/동물 하나)doesn't + 동사원형doesn't runs (X) -> run (O)
Mr. Smith sleeps late. He doesn't get up early.
스미스 씨는 늦게까지 잔다. 그는 일찍 일어나지 않는다. — He가 주어이므로 doesn't + 동사원형(get up)
Jenny has a hamster. She doesn't have a cat.
제니는 햄스터를 가지고 있다. 그녀는 고양이를 가지고 있지 않다. — She 뒤에는 doesn't를 쓰고 has는 have로 변경
My cat runs fast, but it doesn't run in the room.
내 고양이는 빨리 달린다 하지만 그것은 방 안에서 달리지 않는다. — It이 주어이므로 doesn't 사용

33. 부정문의 형태 주의: 동사원형!

don't나 doesn't 뒤에는 반드시 동사의 원래 모습인 '동사원형'을 써야 합니다. ★don't냐 doesn't냐를 결정한 후에는 동사를 건드리지 마세요.
🗂 자주 틀리는 부정문 형태
구분잘못된 표현 (X)바른 표현 (O)
3인칭 단수 부정He doesn't likesHe doesn't like
불규칙 동사 원형She doesn't hasShe doesn't have
동사 위치I like notI don't like
He doesn't like rugby.
그는 럭비를 좋아하지 않는다. — doesn't 뒤에 likes가 아닌 동사원형 like를 씀
They don't go to school.
그들은 학교에 가지 않는다. — don't 뒤에 동사원형 go를 씀

44. be동사와 일반동사 부정문 비교

be동사는 뒤에 not만 붙이면 되지만, 일반동사는 do/does의 도움을 받아야 합니다. ★두 동사의 부정문 방식을 섞어서 쓰지 않도록 주의합니다.
🗂 be동사 vs 일반동사 부정문
동사 종류부정문 만드는 법예시
be동사 (am/are/is)be동사 + notis not / isn't
일반동사don't / doesn't + 동사원형doesn't like
Fred is a soccer player. He isn't a rugby player.
프레드는 축구 선수이다. 그는 럭비 선수가 아니다. — be동사 is의 부정은 isn't
Fred likes soccer. He doesn't like rugby.
프레드는 축구를 좋아한다. 그는 럭비를 좋아하지 않는다. — 일반동사 like의 부정은 doesn't like
