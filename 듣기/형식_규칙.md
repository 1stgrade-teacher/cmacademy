# 🎧 듣기 메이커 형식 규칙

듣기문제 메이커가 만든 HTML을 **`듣기/` 폴더**에 올리면, 사이트가 자동으로

1. **온라인 듣기시험** (TEST 관리 → 새 시험지 → 종류 「듣기시험」): 객관식만, 원래 순서대로, 문제마다 ▶ 음성, 자동 채점·기록
2. **🎧 받아쓰기 숙제** (TEST 관리 → 📸 과제 → 종류 「받아쓰기」): 대본에서 빈칸 자동 생성, 자동 채점·기록

을 만들 수 있어요. 기존 AI강의와 **같은 틀**(`lecturePlayer(…, { audioDir, slides:[{ html, segs }] })`)에 아래 세 가지만 지키면 돼요.
샘플: `듣기/_형식샘플.html` (이름이 `_`로 시작하는 파일은 문제은행에 들어가지 않아요)

---

## 폴더

```
듣기/
  중2-듣기평가/            ← 교재(묶음) 폴더 = 사이트의 「교재」
    index.html             ← (선택) 회차 목록. 다른 강의 폴더와 같은 모양이면 회차 이름을 여기서 읽어요
    1회.html               ← 회차 = 사이트의 「과」
    1회_audio/1.mp3 …      ← 그 회차의 음성 (audioDir)
    2회.html
    2회_audio/…
```

## 1. 문제 슬라이드 (한 문제 = 한 슬라이드)

기존 확인 문제와 같아요.

```html
<div class="g-q">대화를 듣고, 여자가 남자에게 부탁한 일로 가장 적절한 것을 고르시오.</div>
<div class="g-opts">
  <button class="g-opt"><b>①</b>책 반납하기</button>
  <button class="g-opt"><b>②</b>숙제 도와주기</button>
  <button class="g-opt" data-ok="1"><b>③</b>우산 빌려주기</button>   ← 정답에 data-ok="1"
  <button class="g-opt"><b>④</b>점심 사 오기</button>
  <button class="g-opt"><b>⑤</b>사진 찍어 주기</button>
</div>
<div class="g-ans" data-rv="ans"><b>정답</b><span class="a">우산 빌려주기</span><div class="g-exp">해설…</div></div>
```

- 보기가 2개 이상 있는 **객관식만** 듣기시험에 나와요. 그림 보기(그림만 있는 보기)는 아직 지원하지 않아요 → 보기에 글자를 꼭 넣어 주세요.

## 2. 그 문제의 듣기 음성 (둘 중 하나)

- **방법 A (권장)**: 슬라이드 `segs`에서 **대화를 읽는 줄**에 `"hl":"listen"` → `audioDir/<n>.mp3`가 그 문제의 음성이 돼요.
  ```json
  {"html":"…","segs":[
    {"n":2,"text":"1번. 대화를 듣고 …","hl":"q"},
    {"n":3,"text":"W: Tom, it's raining … M: Sure, no problem.","hl":"listen"},   ← 이 줄의 음성 3.mp3
    {"n":4,"text":"정답은 3번 …","hl":"ans","reveal":"ans"}
  ]}
  ```
- **방법 B**: `.g-q`에 직접 표시: `<div class="g-q" data-audio="./1회_audio/3.mp3">…</div>`

⚠️ 듣기 음성에는 **대화(지문)만** 넣고 "정답은 3번" 같은 해설은 넣지 마세요. 학생이 시험 중에 그 음성을 들어요.

## 3. 대본 (받아쓰기 숙제용)

```html
<div class="g-script" data-rv="ans">
  <p>W: Tom, it's raining outside and I didn't bring my umbrella.</p>
  <p>M: Oh, really? I have an extra one in my locker.</p>
</div>
```

- 한 줄에 한 사람의 말 하나, `W:` `M:` `B:` `G:` `Man:` 처럼 **말한 사람 + 콜론**으로 시작하면 이름이 굵게 나와요.
- 대본은 **음성과 똑같이** 써 주세요. 빈칸 정답이 대본 낱말이에요.
- `data-rv="ans"`를 붙이면 강의 화면에서는 정답을 볼 때 함께 보여요 (시험 화면에는 보이지 않아요).

## 빈칸은 이렇게 만들어져요

- 대본에서 3글자 이상 낱말 중, 쉬운 기능어(the, and, you, is …)와 줄임말(it's, I'll)을 빼고 고른 비율(20~50%)만큼 빈칸.
- 같은 과제는 늘 같은 빈칸이에요(과제마다 위치는 달라요).
- 채점: 대소문자·마침표·쉼표·따옴표 차이는 맞게 봐요. 철자가 다르면 틀려요.
