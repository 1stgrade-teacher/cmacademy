기본 정보

상담 시간 규칙

· 예: 상담 30분 · 간격 30분 → 13:00, 13:30, 14:00… / 여유 10분 → 상담과 상담 사이를 10분씩 비워요.
· 최소 3시간 전 → 지금이 오후 1시면 오후 4시부터 고를 수 있어요. 학부모님이 직접 바꾸거나 취소할 수 있는 시한도 같아요.

요일별 상담 가능 시간

한 요일에 시간대를 여러 개 넣을 수 있어요 (예: 10:00~12:00, 14:00~17:00). 시간대가 없는 요일은 예약을 받지 않아요.

예약 페이지 주소

카톡·문자·블로그·학원 홈페이지에 이 주소를 붙여 넣으면 학부모님이 바로 예약하실 수 있어요. 입장 코드 없이 열려요.


      

    

    

      
📆 내 캘린더에 예약 자동으로 띄우기 (구독 주소)

      

      
· 구글 캘린더(컴퓨터): 왼쪽 '다른 캘린더' 옆 + → URL로 추가 → 이 주소 붙여넣기
· 네이버 캘린더: 환경설정 → 캘린더 구독 → URL 입력
· 아이폰: 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가

      · 캘린더 앱이 몇 시간마다 새로 읽어 와서, 새 예약이 캘린더에 보이기까지 시간이 걸릴 수 있어요 (구글은 길면 반나절). 바로 확인은 이 화면에서 해 주세요.
· 이 주소에는 학부모 연락처가 들어 있으니 다른 사람에게 보내지 마세요.
