웹 배포용 파일 사용법 (GitHub + Vercel)
=======================================

이 폴더(또는 ZIP을 푼 폴더) 안의 파일과 폴더를 그대로 GitHub 저장소 맨 앞에 올리면 Vercel이 바로 배포할 수 있어요.

[GitHub에 올리기]
1. GitHub에서 새 저장소(Repository)를 만듭니다.
2. [Add file] → [Upload files]를 누르고, 폴더 '안에 있는' 파일과 폴더를 끌어다 놓습니다.
3. 한 번에 올릴 수 있는 파일은 100개까지예요. 음성 파일이 많으면 강의를 한두 개씩 나눠서 올리거나
   GitHub Desktop 프로그램으로 올리세요.

[Vercel에서 배포하기]
1. Vercel에서 [Add New → Project]로 그 저장소를 고릅니다.
2. Framework Preset은 'Other', Build Command와 Output Directory는 비워 둡니다.
3. [Deploy]를 누르면 끝이에요.

[꼭 지켜 주세요]
- 올린 뒤에 파일 이름이나 음성 폴더 이름을 GitHub에서 직접 바꾸지 마세요.
  이름을 바꾸고 싶으면 스튜디오에서 새 이름으로 다시 내보내 올리세요.
  (강의 파일 안에 음성 폴더 이름이 함께 적혀 있어서, 스튜디오가 두 이름을 같이 맞춰 줍니다.)
- 모의고사 지문 등 저작권이 있는 자료는 공개 사이트에 올리지 말고, 수강생에게만 주소를 알려 주세요.
