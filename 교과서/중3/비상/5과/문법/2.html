🎧 목적을 나타내는 so that ~ can — AI강의

11. 의미와 기본 형태

★ 「so that+주어+can+동사원형」은 ‘~하기 위해서’라는 목적을 나타낸다. 주절의 행동을 한 이유가 that절에 제시된다.
🗂 so that ~ can의 기본 구조
구분형태의미
현재·미래의 목적so that+주어+can+동사원형~가 …할 수 있도록 / ~하기 위해서
과거의 목적so that+주어+could+동사원형~가 …할 수 있도록 / ~하기 위해서
주의can/could 뒤에는 반드시 동사원형could won ✕ → could win ○
I read the instructions for the machine so that I can use it without any problem.
나는 문제없이 그것을 사용하기 위해 그 기계의 설명서를 읽는다. — 목적: 문제없이 사용할 수 있도록
She studies hard so that she can pass the test.
그녀는 시험에 합격하기 위해 열심히 공부한다. — so that절이 공부하는 목적을 나타냄
The government built night shelters so that homeless people could sleep there.
정부는 노숙자들이 그곳에서 잘 수 있도록 야간 쉼터를 지었다. — 주절이 과거이므로 could 사용

22. in order that / in order to로 바꾸기

★ 「so that ~ can」은 「in order that ~ can」으로 바꿀 수 있다. 주절과 종속절의 주어가 같으면 「in order to+동사원형」으로 바꿀 수 있다.
🗂 전환 규칙
조건전환 가능 형태예
주절과 종속절의 주어가 같거나 다름in order that+주어+can/could+동사원형so that she could win → in order that she could win
주절과 종속절의 주어가 같음in order to+동사원형Linda ... so that she could win → Linda ... in order to win
주절과 종속절의 주어가 다름in order to로 전환 불가I bought her a phone so that she could use it. → I bought her a phone in order to use it. ✕
Linda went through hard training so that she could win the game.
Linda는 그 경기에서 이기기 위해 힘든 훈련을 받았다. — could 뒤에는 동사원형 win
Linda went through hard training in order that she could win the game.
Linda는 그 경기에서 이기기 위해 힘든 훈련을 받았다. — so that을 in order that으로 전환
Linda went through hard training in order to win the game.
Linda는 그 경기에서 이기기 위해 힘든 훈련을 받았다. — 주어가 Linda로 같으므로 in order to 가능

33. so that ~ can과 so ~ that ... can의 구별

★ 「so that ~ can」은 목적을, 「so+형용사/부사+that ... can」은 결과를 나타낸다. so 바로 뒤에 형용사나 부사가 오면 결과 구문일 가능성이 높다.
🗂 목적 구문과 결과 구문 비교
구문형태의미판단 기준
목적so that+주어+can/could+동사원형~하기 위해서so와 that이 붙어 있고, that절이 목적
결과so+형용사/부사+that+주어+can/could+동사원형매우 ~해서 …할 수 있다so 뒤에 형용사/부사가 옴
해석 차이got up early so that she could take the bus버스를 타기 위해 일찍 일어났다목적
해석 차이is so smart that she can solve any problem매우 똑똑해서 어떤 문제든 풀 수 있다결과
My sister got up early so that she could take her school bus.
내 여동생은 통학 버스를 타기 위해 일찍 일어났다. — 목적: 버스를 타기 위해
My sister is so smart that she can solve any problem.
내 여동생은 매우 똑똑해서 어떤 문제든 풀 수 있다. — 결과: 매우 똑똑해서 풀 수 있음
I practice running so that I can win the race.
나는 경주에서 이기기 위해 달리기를 연습한다. — so 뒤에 형용사/부사가 없으므로 목적 구문

44. 조동사 can, could, may, will의 사용

★ 목적절의 조동사는 의미와 시제에 따라 can, could, may, will 등으로 바뀔 수 있다. 과거의 목적은 주로 could를 쓴다.
🗂 that절 조동사 선택
조동사쓰임예시 의미
can현재·미래 상황에서 ‘할 수 있도록’합격할 수 있도록
could과거 상황에서 ‘할 수 있도록’사용할 수 있도록 했다
may격식체에서 목적·허가의 뉘앙스도움을 받을 수 있도록
will미래의 결과나 의지를 강조참여하게 하려고
I take piano lessons so that I can play it well.
나는 피아노를 잘 치기 위해 피아노 수업을 듣는다. — 현재의 목적이므로 can
The charity started a campaign so that people could provide aid for refugees.
그 자선 단체는 사람들이 난민들에게 도움을 제공할 수 있도록 캠페인을 시작했다. — 주절이 과거이므로 could
I bought my daughter a smartphone so that she could use it abroad.
나는 딸이 해외에서 그것을 사용할 수 있도록 스마트폰을 사 주었다. — 주절과 종속절의 주어가 다름
